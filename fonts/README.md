# Inter Variable font

`inter-latin-wght-normal.woff2` is the unmodified Latin normal variable font from
[`@fontsource-variable/inter` 5.3.0](https://www.npmjs.com/package/@fontsource-variable/inter/v/5.3.0).
It is distributed under the matching package's SIL Open Font License 1.1, copied
verbatim into [OFL.txt](OFL.txt). Font copyright belongs to The Inter Project Authors;
see [upstream Inter](https://github.com/rsms/inter).

SHA-256: `3100e775e8616cd2611beecfa23a4263d7037586789b43f035236a2e6fbd4c62`.

The CSS references this file relatively, so consumer bundlers can emit a same-origin
font asset. Consumers should set their asset inline limit to zero to retain a font URL.
